# 🐾 FurNet — Rede social de pets

> A **FurNet** é uma API que simula uma pequena rede social voltada para pets.  
> Usuários podem criar perfis e cadastrar seus animais, adicionando fotos e informações como nome, idade e espécie.  
> A proposta é oferecer um espaço virtual para compartilhar a fofura dos pets com o mundo.  
> Não há interação entre os usuários — o foco é a exibição das postagens de cada bichinho, como um álbum online de pets.

## 🧰 Tecnologias Utilizadas

- **Linguagem:** C# (.NET 8)
- **Framework:** ASP.NET Core - Minimal API
- **ORM:** Entity Framework Core
- **Banco de Dados:** SQLite
- **Front-end:** JavaScript + React
- **Versionamento:** Git + GitHub

## 🚀 Como executar o projeto

### 🔧 Pré-requisitos

- [.NET SDK 8.0+](https://dotnet.microsoft.com/en-us/download)
- [SQLite](https://sqlite.org/download.html)
- Git instalado

### 📂 Passos para rodar:

```bash
# 1. Clone o repositório
git clone https://github.com/seuUsuario/FurNet

# 2. Acesse a pasta do projeto
cd FurNet

# 3. Restaure os pacotes
dotnet restore

# 4. Execute a aplicação
dotnet run
